# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in proto2pydantic, please report it
responsibly by emailing **security@protocgen.dev** rather than opening a public issue.

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |

## Disclosure Policy

- We follow [coordinated vulnerability disclosure](https://en.wikipedia.org/wiki/Coordinated_vulnerability_disclosure)
- Security fixes are prioritized and released as patch versions
- CVEs are filed for confirmed vulnerabilities when applicable
